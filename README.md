# Scopo

Questo documento rappresenta l'indice principale della documentazione
dell'English Learning Repository (ELR).

Il suo scopo è fornire una panoramica organizzata delle specifiche ufficiali,
della loro collocazione e del loro ruolo all'interno dell'architettura.

L'indice non introduce requisiti tecnici e non sostituisce alcuna
specifica.

Per i dettagli di un componente è sempre necessario fare riferimento al
documento corrispondente.

la versione architetturale ufficiale del sistema.
