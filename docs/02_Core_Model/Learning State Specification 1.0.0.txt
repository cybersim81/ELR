================================================================================
Scopo
=====

La Learning State Specification definisce il modello dello stato di
apprendimento associato ai Learning Object all'interno dell'English Learning
Repository (ELR).

Il Learning State rappresenta la condizione corrente di una conoscenza
linguistica rispetto al percorso di apprendimento dell'utente.

Il Learning State non rappresenta:

* la conoscenza linguistica;

* il contenuto del Learning Object;

* l'algoritmo di calcolo della Mastery;

* la cronologia completa delle interazioni.

La conoscenza è rappresentata attraverso:

* Learning Object;

* Anchor;

* Knowledge Statement;

* Knowledge Category.

Lo stato di apprendimento rappresenta invece la relazione dinamica tra
utente e conoscenza.

================================================================================
Responsabilità del documento
============================

Questo documento definisce:

* il concetto di Learning State;

* la relazione tra Learning State e Learning Object;

* gli stati concettuali supportati;

* le transizioni possibili;

* i principi di aggiornamento.

Questo documento NON definisce:

* algoritmo di Mastery;

* scheduling degli esercizi;

* selezione automatica degli esercizi;

* produzione di Evidence;

* estrazione della conoscenza.

Queste responsabilità appartengono ai componenti dedicati.

================================================================================
Principio fondamentale
======================

Un Learning Object rappresenta:

"Quale conoscenza linguistica deve essere acquisita."

Un Learning State rappresenta:

"Qual è la condizione corrente di acquisizione di quella conoscenza."

La conoscenza rimane stabile.

Lo stato può evolvere.

================================================================================
3. Learning State Properties
============================

Un Learning State può contenere:

---

## Learning Object Reference

Riferimento al Learning Object a cui lo stato appartiene.

---

## Current State

Stato corrente della conoscenza.

---

## Mastery Reference

Riferimento alla Mastery associata al rapporto tra User e Learning Object.

La Mastery Reference non costituisce il Mastery State completo.

Il Mastery State rappresenta il modello della padronanza dell'utente
rispetto al Learning Object.

Il Learning State può utilizzare informazioni derivate dal Mastery State
per descrivere l'evoluzione della condizione di apprendimento.

Il valore numerico, la rappresentazione quantitativa e il calcolo della
Mastery appartengono al Mastery Engine.

---

## Evidence History Reference

Riferimento alle Evidence utilizzate per aggiornare lo stato.

La Evidence non costituisce parte della conoscenza.

================================================================================
4. Learning State Model
=======================

Il modello ELR definisce i seguenti stati concettuali:

---

## Unknown

La conoscenza non è ancora stata identificata come parte del percorso
dell'utente.

Non esiste evidenza sufficiente di acquisizione.

---

## Introduced

La conoscenza è stata presentata o resa disponibile all'utente.

Non implica acquisizione.

---

## Practicing

L'utente sta interagendo con esercizi o attività relative alla conoscenza.

Non implica padronanza.

---

## Developing

Sono presenti segnali di utilizzo o apprendimento della conoscenza.

La conoscenza è in fase di consolidamento.

---

## Established

La conoscenza mostra evidenza sufficiente di utilizzo stabile.

Non significa conoscenza permanente.

---

## Needs Review

La conoscenza richiede nuovo consolidamento.

Può derivare da:

* mancato utilizzo;

* errori osservati;

* decadimento della Mastery.

================================================================================
6. Relationship with Mastery
============================

Learning State e Mastery sono concetti correlati ma distinti.

Mastery rappresenta:

"Quanto è consolidata la conoscenza."

Learning State rappresenta:

"La condizione del percorso di apprendimento."

Esempio:

Un Learning Object può avere:

State:

Practicing

Mastery:

bassa

oppure:

State:

Established

Mastery:

alta

La relazione precisa è gestita dal Mastery Engine.

================================================================================
7. Relationship with Evidence
=============================

Il Learning State può essere aggiornato sulla base di Evidence.

Esempi:

Uso corretto:

può supportare una transizione verso stati più consolidati.

Errore relativo a conoscenza esistente:

può supportare una transizione verso Needs Review.

Richiesta di chiarimento:

può fornire evidenza di incertezza.

La Evidence non determina automaticamente una transizione.

================================================================================
8. Learning State and Learning Object Lifecycle
===============================================

La creazione di un Learning Object non implica automaticamente la padronanza.

Esempio:

CREATE Learning Object:

Anchor:

make + mistake

Learning State iniziale:

Introduced

Successivamente:

Esercizi completati:

Practicing

Uso corretto ripetuto:

Developing

Uso stabile:

Established

================================================================================
10. Principles
==============

---

## LS-001 — State is not Knowledge

Lo stato di apprendimento non modifica il contenuto della conoscenza.

---

## LS-002 — State is User Specific

Lo stesso Learning Object può avere Learning State differenti per utenti
differenti.

---

## LS-003 — State is Evidence Driven

Le transizioni di stato devono essere supportate da osservazioni o processi
validi.

---

## LS-004 — State Evolution is Separate from Mastery Calculation

Il cambiamento dello stato non coincide con il calcolo della Mastery.

================================================================================
Principio conclusivo
====================

Il Learning Object rappresenta la conoscenza.

La Evidence rappresenta ciò che è stato osservato.

La Mastery rappresenta il livello di consolidamento.

Il Learning State rappresenta la condizione evolutiva della relazione tra
utente e conoscenza.

L'ELR conserva conoscenza.

Il Mastery Engine interpreta evidenze di padronanza.

Il Learning State rappresenta il percorso di acquisizione.
