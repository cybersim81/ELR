# 6. Implementation Discipline

================================================================================

The roadmap is a conformance-resolution plan, not an authorization to
implement every downstream responsibility immediately.

For each remaining finding:

1. inspect the authoritative specification;
2. identify the exact implementation gap;
3. implement only the required responsibility;
4. add or update focused verification;
5. run the complete test suite;
6. record the verified result;
7. close the finding only after evidence is available.

No downstream item should be marked COMPLETE without corresponding repository
evidence and passing verification.
