================================================================================
Scopo
================================================================================

La Learning Activity Specification definisce il modello concettuale delle
attività di apprendimento generate utilizzando la conoscenza presente nell'ELR
e le informazioni di padronanza prodotte dal Mastery Engine.


La Learning Activity rappresenta il livello di collegamento tra:


• conoscenza disponibile;

• stato di apprendimento dell'utente;

• azione didattica proposta.


La Learning Activity non rappresenta:


• conoscenza linguistica;

• Learning Object;

• esercizio specifico;

• stato di Mastery;

• Evidence;

• protocollo di interazione.


================================================================================
Principio fondamentale
================================================================================

Una Learning Activity risponde alla domanda:


"Quale attività è appropriata per aiutare l'utente rispetto a una conoscenza?"


Non risponde alla domanda:


"Quale conoscenza deve essere memorizzata?"


La conoscenza appartiene all'ELR.

La padronanza appartiene al Mastery Engine.

L'attività appartiene al Learning Activity Layer.

Boundary architetturale
================================================================================

Relazione:

        |

        +

        |

        |

Learning Activity


        |

La Learning Activity è un process object e non costituisce una nuova unità di
conoscenza persistente del repository.

La Learning Activity non modifica direttamente il Learning Object né il
Mastery State.


================================================================================
Responsabilità
================================================================================

La Learning Activity Specification definisce:


• modello delle attività;

• relazione tra attività e Learning Object;

• criteri generali di selezione;

• obiettivo didattico dell'attività;

• relazione architetturale con Mastery State ed Exercise System.


================================================================================
Non responsabilità
================================================================================

La Learning Activity non definisce:


• generazione degli esercizi;

• formato delle domande;

• valutazione delle risposte;

• feedback linguistico dettagliato;

• algoritmi di Mastery;

• scheduling adattivo autonomo.


Queste responsabilità appartengono a:


Exercise System:

generazione e gestione degli esercizi


Mastery Engine:

valutazione e aggiornamento della padronanza


Adaptive Review (futura estensione):

selezione e scheduling adattivo delle Learning Activity


================================================================================
Learning Activity Concept
================================================================================

Una Learning Activity rappresenta una proposta strutturata di intervento
didattico associata a uno o più Learning Object.


Una Learning Activity contiene concettualmente:


• obiettivo di apprendimento;

• riferimento alla conoscenza target;

• livello di intervento;

• relazione con Mastery;

• tipo di attività richiesto.


Questi elementi sono derivati o riferiti a partire dalle fonti autorevoli e
non costituiscono una seconda fonte persistente della conoscenza.


================================================================================
Relazione con Learning Object
================================================================================

Ogni Learning Activity deve riferirsi almeno a un Learning Object.


La Learning Activity non modifica il Learning Object.


Esempio:


Learning Object:


Anchor:

make + mistake


Knowledge Statement:

Per esprimere l'azione di commettere un errore si usa
"make a mistake".


Possibili Learning Activity:


• riconoscimento della collocazione;

• produzione guidata;

• produzione libera.


La conoscenza rimane invariata.


================================================================================
Relazione con Mastery
================================================================================

La scelta di una Learning Activity può dipendere da:


• livello di Mastery;

• storico delle Evidence;

• difficoltà osservate;

• necessità di consolidamento.


La Learning Activity utilizza questi segnali per definire l'intervento, ma non
modifica direttamente il Mastery State.


Esempio:


Mastery bassa:


Attività:

riconoscimento guidato.


Mastery intermedia:


Attività:

produzione controllata.


Mastery alta:


Attività:

produzione libera.


================================================================================
Learning Activity Types
================================================================================

Il modello può includere differenti categorie di attività.


================================================================================
Recognition Activity
================================================================================

Obiettivo:


riconoscere una conoscenza linguistica.


Esempio:


Identificare la forma corretta:


make a mistake

vs

do a mistake


================================================================================
Controlled Production Activity
================================================================================

Obiettivo:


produrre una conoscenza con vincoli.


Esempio:


Completa:


I made a ______ yesterday.


================================================================================
Free Production Activity
================================================================================

Obiettivo:


utilizzare autonomamente una conoscenza.


Esempio:


Descrivere un'esperienza usando:

make + mistake


================================================================================
Contrast Activity
================================================================================

Obiettivo:


distinguere conoscenze linguistiche vicine.


Esempio:


since

vs

for


================================================================================
Review Activity
================================================================================

Obiettivo:


consolidare una conoscenza già acquisita.


Può essere generata sulla base di:


• decadimento temporale;

• rischio di perdita;

• Evidence precedente.


La selezione e lo scheduling adattivi di Review Activity rimangono una
responsabilità futura di Adaptive Review.


================================================================================
Activity Selection
================================================================================

La selezione delle attività può utilizzare:


• Learning Object;

• Mastery State;

• priorità didattiche.


La selezione non modifica:


• conoscenza;

• Mastery;

• repository.


================================================================================
Activity Lifecycle
================================================================================

Il ciclo concettuale è:


Learning Object

        |

        v

Mastery Analysis

        |

        v

Learning Activity Generation

        |

        v

Exercise System

        |

        v

User Interaction

        |

        v

Evidence Generation


La valutazione della risposta e la produzione dell'Evidence sono effettuate
secondo le responsabilità definite dall'Exercise System e dall'Evidence Model.


================================================================================
Evidence Generation
================================================================================

Una Learning Activity può portare a nuovi eventi osservabili attraverso la
realizzazione dell'attività e l'interazione dell'utente.


Questi eventi possono contribuire alla produzione di Evidence secondo il
modello Evidence e i processi proprietari che lo utilizzano.


La Learning Activity non produce direttamente Evidence come modello
proprietario e non produce direttamente conoscenza.

================================================================================
Anti-corruption Rules
================================================================================

Una Learning Activity non deve:


• contenere conoscenza autorevole non presente nell'ELR;

• modificare Learning Object;

• trasformare un esercizio in conoscenza;

• sostituire il Mastery Engine;

• diventare una fonte persistente autonoma di Evidence;

• incorporare il protocollo di interazione come propria responsabilità.


================================================================================
Principio conclusivo
================================================================================

La Learning Activity rappresenta il collegamento tra conoscenza e azione
didattica.


L'ELR conserva ciò che deve essere imparato.


Il Mastery Engine misura quanto è stato imparato.


La Learning Activity determina quale tipo di intervento è appropriato.


L'Exercise System realizza concretamente l'interazione.


Adaptive Review, quando sarà progettato, potrà selezionare e schedulare le
Learning Activity senza sostituirle.
