================================================================================
Scopo
=====

La ELR Data Model Specification definisce il modello strutturale dei dati
persistenti utilizzati dall'Educational Learning Repository (ELR).

Il Data Model rappresenta il livello attraverso cui i concetti definiti nel
Domain Model vengono trasformati in entità persistenti.

Il Data Model definisce:

* entità persistenti;

* relazioni tra entità;

* attributi principali;

* vincoli di consistenza.

Il Data Model non definisce:

* algoritmi di estrazione della conoscenza;

* criteri didattici;

* calcolo della Mastery;

* logiche conversazionali.

================================================================================
Responsabilità del documento
============================

Questo documento definisce:

* struttura dati del Learning Object;

* struttura dati dell'Anchor;

* struttura dati del Knowledge Statement;

* struttura dati della Learning State;

* relazioni tra entità ELR;

* principi di persistenza.

Questo documento NON definisce:

* creazione automatica dei dati;

* approvazione delle modifiche;

* generazione degli esercizi;

* interpretazione delle Evidence.

Queste responsabilità appartengono ai componenti dedicati.

================================================================================
Principio fondamentale
======================

Il Data Model deve rappresentare conoscenza linguistica persistente senza
confondere:

conoscenza

con

processo che l'ha generata.

Il Data Model rappresenta i concetti persistenti definiti dal Domain Model.

Il Domain Model costituisce l'autorità per i confini, le responsabilità e le
relazioni del modello di dominio.

Il Data Model non può ridefinire autonomamente tali confini o responsabilità.

Il repository conserva:

* Learning Object approvati;

* stato di apprendimento;

* relazioni linguistiche;

ma non conserva:

* conversazioni;

* errori grezzi;

* ragionamenti temporanei della KEP.

Il Learning Object è l'unità minima persistente della conoscenza.

Anchor, Knowledge Statement e Knowledge Category partecipano alla struttura

Il Knowledge Statement non costituisce una entità persistente autonoma.

Il Learning State è persistente e User-specific, ma non costituisce conoscenza

Le Evidence non appartengono al repository della conoscenza.

Sono gestite secondo l'Evidence Model e i processi dedicati.


================================================================================
2. Learning Object Entity
=========================

Un Learning Object contiene:

* identificativo unico;

* Anchor associato;

* Knowledge Statement;

* Knowledge Category;

* metadati di gestione.

Il Learning State non appartiene al Learning Object.

Il Learning State è associato al Learning Object in relazione allo User
e costituisce uno stato didattico User-specific.

Un Learning Object rappresenta una sola conoscenza atomica.

================================================================================
3. Anchor Entity
================

L'Anchor identifica l'unità linguistica a cui la conoscenza è associata.

Un Anchor può rappresentare:

* parola;

* espressione;

* collocazione;

* costruzione;

* formula comunicativa.

Un Anchor non rappresenta:

* categoria grammaticale astratta;

* errore;

* spiegazione metalinguistica.

================================================================================
4. Knowledge Statement
======================

Il Knowledge Statement rappresenta la conoscenza associata all'Anchor
all'interno del Learning Object.

Il Knowledge Statement è una componente del Learning Object e non costituisce
una entità persistente autonoma.

Un Knowledge Statement deve essere:

* atomico;
* positivo;
* riutilizzabile;
* comprensibile.

Un Learning Object contiene una conoscenza principale.

Eventuali spiegazioni estese appartengono a livelli descrittivi separati.

Il Knowledge Statement non possiede:

* identità persistente indipendente;
* ciclo di vita autonomo;
* versionamento indipendente.

La sua persistenza e la sua evoluzione sono gestite attraverso il Learning
Object al quale appartiene.

================================================================================
5. Knowledge Category Entity
============================

La Knowledge Category classifica il tipo di conoscenza rappresentata.

Categorie definite:

* Meaning

* Function

* Context

* Construction

* Complement

* Morphology

La categoria supporta ricerca e organizzazione.

La Knowledge Category è un elemento classificatorio del Data Model e non
costituisce un membro dell'aggregate Learning Object definito dal Domain Model.

La Knowledge Category non possiede un lifecycle derivato dal Learning Object
e non modifica i confini dell'aggregate.

Non determina automaticamente la struttura del Learning Object.


================================================================================
6. Learning State Entity
========================

Il Learning State rappresenta lo stato didattico associato a un Learning
Object.

Contiene informazioni relative a:

* stato di apprendimento;

* livello di consolidamento;

* informazioni necessarie al Mastery Engine.

Il Learning State non rappresenta conoscenza linguistica.

Le relazioni tra Learning Object e Anchor, Knowledge Statement e Knowledge
Category rappresentano composizione o associazione interna alla struttura
persistente del Learning Object.

Non devono essere interpretate come relazioni tra entità di conoscenza tutte
dotate di ciclo di vita persistente autonomo.

Il Knowledge Statement appartiene al Learning Object.

La Knowledge Category classifica il Learning Object e non costituisce
conoscenza autonoma.


Un Anchor può essere associato a più Learning Object quando rappresenta
conoscenze indipendenti.

Esempio:

Anchor:

look forward to

Learning Object 1:

look forward to + verb-ing

Learning Object 2:

look forward to = attendere con piacere

================================================================================
8. Repository Consistency Rules
===============================

Il Data Model deve garantire:

---

## Atomicità

Ogni Learning Object rappresenta una conoscenza indipendente.

---

## Unicità

Non devono esistere duplicati concettuali dello stesso Learning Object.

---

## Separazione

Conoscenza, Evidence e processo devono rimanere separati.

---

## Persistenza controllata

Solo conoscenze approvate dalla Learning Review entrano nel repository.

================================================================================
10. Versioning
==============

Le strutture persistenti devono supportare evoluzione controllata.

Il versioning deve consentire:

* modifica delle formulazioni del Learning Object;
* evoluzione del contenuto del Knowledge Statement attraverso il Learning
  Object;
* tracciabilità delle modifiche.

Il Knowledge Statement non possiede un versionamento indipendente.

Qualsiasi modifica sostanziale al Knowledge Statement deve essere trattata
come evoluzione del Learning Object al quale appartiene.

La storia delle modifiche non sostituisce l'identità del Learning Object.

================================================================================
Principi conclusivi
===================

## DATA-001 — Repository stores approved knowledge

Il Data Model conserva solo conoscenza approvata.

## DATA-002 — Knowledge and Process Separation

Il Data Model non conserva il processo che ha generato la conoscenza.

## DATA-003 — Learning Object is atomic persistence unit

Il Learning Object è l'unità minima persistente della conoscenza.

## DATA-004 — Learning Object centered persistence

La struttura della persistenza della conoscenza è organizzata intorno al
Learning Object.

L'Anchor identifica l'unità linguistica associata alla conoscenza e può essere
condiviso da più Learning Object indipendenti.


================================================================================
Principio conclusivo
====================

Il Data Model rappresenta la struttura persistente dell'ELR.

Il Domain Model definisce cosa rappresenta la conoscenza.

Il Data Model definisce come viene conservata.

La KEP propone modifiche.

La Learning Review approva.

L'ELR conserva conoscenza linguistica evolutiva.
