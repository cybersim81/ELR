-------------------------------------------------------------------------------
ADR-015 — Mastery Evidence and Mastery Engine Separation
-------------------------------------------------------------------------------

Decision

L'aggiornamento del Mastery State è responsabilità esclusiva del Mastery
Engine.

Qualunque componente autorizzato può produrre Mastery Evidence secondo le
regole definite dalla Evidence Model Specification.

La Mastery Evidence rappresenta esclusivamente proprietà osservabili
dell'evento di apprendimento.

La Mastery Evidence non contiene:

• valutazioni sul proprio impatto;
• modifiche dirette del Mastery State;
• decisioni finali di aggiornamento.

Il Mastery Engine interpreta la Mastery Evidence secondo una propria politica
di aggiornamento e modifica il Mastery State relativo allo specifico User e
Learning Object.

Motivazione

La padronanza può essere influenzata da molteplici fonti di evidenza.

La separazione tra produzione delle Evidence e aggiornamento del Mastery State
mantiene responsabilità architetturali indipendenti.

Il componente che produce un'evidenza non deve essere responsabile della
definizione dello stato finale di padronanza.

Conseguenze

La produzione delle Mastery Evidence è separata dalla gestione del Mastery
State.

Il Mastery Engine costituisce il componente responsabile
dell'interpretazione delle Evidence e dell'aggiornamento dello stato di
padronanza dello specifico User rispetto allo specifico Learning Object.

Le politiche operative di aggiornamento sono definite nella
Mastery Engine Specification.

Il Mastery State non diventa una proprietà del Learning Object a seguito
dell'aggiornamento.
