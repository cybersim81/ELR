## Next Session Procedure

A new implementation session must proceed in this order:

1. Read this checkpoint completely.
2. Read `docs/00_Bootstrap/05_Implementation_Alignment_Roadmap.txt`.
3. Read the current IA-08 implementation conformance plan under
   `docs/07_Implementation/`.
4. Read the relevant authoritative normative source for IA-08-A03.
5. Inspect the existing repository implementation.
6. Determine whether IA-08-A03 represents an actual behavioral or structural
   conformance gap.
7. Do not infer a gap merely from the absence of a particular class, file,
   service, or naming convention.
8. Implement only a confirmed gap.
9. Run focused tests.
10. Run the complete test suite.
11. Record the verification result.
12. Update implementation documentation and continuity state.
13. Only then establish the next finding.
