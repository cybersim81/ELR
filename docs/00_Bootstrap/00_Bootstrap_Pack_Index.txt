## ELR Bootstrap Pack

### Purpose

This Bootstrap Pack establishes the consolidated starting state for
implementation work on ELR.

It is a continuity and orientation package.

It does not replace the authoritative normative specifications, architecture
documents, ADRs, repository source code, tests, or implementation plans.

Where a conflict exists, the authoritative normative source prevails and this
Bootstrap Pack must be updated accordingly.

## Current LearningObject Lifecycle

The normative LearningObject lifecycle is:

Candidate
↓
Proposed
↓
Active
↓
Retired

`Reviewed`, `Approved`, and `Rejected` are not LearningObject lifecycle
states.

They belong to the Change Proposal review process and must not be introduced
into the LearningObject lifecycle.

---

## Versioning Boundary

LearningObject is the primary unit of knowledge versioning.

KnowledgeStatement is an aggregate member / knowledge value.

Version is immutable and explicitly belongs to LearningObject through
`learning_object_id`.

Version history is distinct from operational Audit history.

Audit records must not be used as a substitute for immutable Version history.
