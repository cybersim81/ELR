# 11. Discrepancy Classification
================================================================================

Any implementation discrepancy must be classified as one of:

A. IMPLEMENTATION DEFECT

The implementation does not satisfy an approved requirement.

B. TEST DEFECT

The test does not correctly represent an approved requirement.

C. DOCUMENTATION DEFECT

The documentation does not accurately describe the verified implementation
state.

D. TECHNICAL DECISION

A technical implementation choice is required without changing architectural
responsibility.

E. ARCHITECTURAL CHANGE

The implementation reveals that the approved architecture itself must change.

Architectural changes require the appropriate architectural governance process.

Implementation work must not silently introduce architectural changes.
